# VQ's Rocket Science Academy — Preview

Repositorio público de **vista previa** para la landing de VQ's Rocket Science Academy.

Este repositorio contiene únicamente la salida compilada necesaria para revisión pública y el workflow de despliegue de GitHub Pages. El repositorio de trabajo, código fuente, documentación interna y borradores legales permanecen separados y privados.

Sitio público de revisión:

`https://quezadav.github.io/vq-rsa-preview/`

## Alcance y privacidad

- La preview es **pública en Internet**.
- No deben copiarse aquí `docs/`, fuentes de trabajo, borradores legales, archivos originales de producción ni material interno.
- Las imágenes visibles en la landing forman parte del sitio publicado y, por tanto, son públicamente accesibles desde esta preview.
- La relación familiar de las personas retratadas no se expone en copy, captions ni `alt` públicos.
- Este repositorio no es el repositorio canónico del proyecto ni debe usarse para desarrollo.
